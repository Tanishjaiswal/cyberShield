# CyberShield: Network Intrusion Detection Using Machine Learning

## About the Project
CyberShield is a machine learning project that detects
potential network intrusions using the UNSW-NB15 dataset.

## Objectives
- Analyse network traffic data.
- Identify normal and malicious network activity.
- Train Logistic Regression and Decision Tree models.
- Evaluate model performance using classification metrics.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Dataset
UNSW-NB15 Dataset:
https://research.unsw.edu.au/projects/unsw-nb15-dataset

## Machine Learning Models
- Logistic Regression
- Decision Tree Classifier

## Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1-score
- Confusion Matrix
